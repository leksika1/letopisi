# Правила интерфейса «Цифровые Летописи природы»

Пользователь — научный сотрудник заповедника. Ему нужно быстро найти наблюдение и убедиться, что оно взято из книги верно. Жюри смотрит на то же самое: запрос → таблица → источник с подсветкой → правка → выгрузка. Интерфейс — спокойный рабочий инструмент архива, не лендинг: плотный, читаемый, без декора.

## Главные принципы

1. **Источник — доказательство.** Страница книги с подсвеченной цитатой — самый важный экран. Она всегда видна рядом с записью, а не внизу длинной карточки.
2. **Сначала запрос, потом фильтры.** Строка «спросите обычными словами» и 4 примера жюри — главное на экране. Полная панель фильтров свёрнута.
3. **Таблица — рабочая поверхность.** Плотные строки, выравнивание, табличные цифры, понятные статусы. Никаких карточек вместо строк.
4. **Сомнение видно сразу.** Флаги и статус читаются без наведения: цвет + значок + число; расшифровка — во всплывающей подсказке и в карточке.
5. **Один акцентный цвет.** Зелёный «лесной» — только для действий и выбранного. Предупреждения — янтарный, ошибки — красный. Всё остальное — нейтральное.

## Типографика

- Интерфейс: `Inter, "Segoe UI", system-ui, sans-serif`. Основной текст 14px / 20px, таблица 13.5px / 20px, подписи 12.5px.
- Заголовок продукта в шапке — `"PT Serif", Georgia, serif`, 18px, полужирный. Больше нигде serif не использовать.
- Числа и даты в таблице — `font-variant-numeric: tabular-nums`, выравнивание: даты влево, значения вправо.
- Латинские названия — курсив, цвет `--muted`: «Лось · *Alces alces*».
- Подписи полей — обычный регистр, 12.5px, `--muted`. **Никаких ПРОПИСНЫХ подписей** (сейчас «ВИД (РУС., ЛАТ., РОД)» — заменить на «Вид»).
- Тексты по-русски, с маленькой буквы в середине предложения, без восклицательных знаков. Кнопки — глагол: «Найти», «Скачать Excel», «Подтвердить».

## Сетка и отступы

- Шкала отступов 4px: 4, 8, 12, 16, 24, 32. Радиус 6px (поля, кнопки, панели), 999px — чипы. Тени только у всплывающих элементов (`0 4px 16px rgba(0,0,0,.08)`).
- Основная ширина — на весь экран с полями 24px; читаемые блоки текста ≤ 72 символов.
- Целевые разрешения: 1440×900 (основное, на нём демо), 1280×800, 1024×768. Горизонтального скролла страницы нет ни на одном.

## Раскладка главного экрана

```
┌ Шапка 56px: «Цифровые Летописи природы» · Поиск · На проверку · Сохранённые · Документы · Качество      Проверяющий [____] ┐
├ Запрос ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ [ Спросите обычными словами…                                                                    ] [Найти]                 │
│ Примеры жюри: (Макарова и Сметанников 1995–96) (лось по хронологии) (публикации о буром медведе) (зацветание герани)       │
│ Понято: [вид: Лось ×] [годы: 1995, 1996, 2020 ×] [по дате ↑ ×]   «2022 → 2020: книги за 2022 нет»            Сбросить     │
├ Фильтры (одна строка): [Вид ▾] [Наблюдатель ▾] [Место ▾] [Годы ▾] [Фенофаза ▾]  [Все фильтры ▸]  ☐ только сомнительные   │
├──────────────────────────────── таблица 56% ──────────────────────┬──────────── панель записи 44%, sticky ─────────────────┤
│ Найдено 133 · [Excel] [CSV] [☆ Сохранить]                          │ Лось · Alces alces            [Подтвердить][Исправить]│
│ Дата │ Объект │ Событие │ Место │ Значение │ Источник │ ●          │ ┌ Страница 499, книга 2020 ─────── − 100% + ⤢ ┐        │
│ ...  строки 44px, выбранная — полоса --accent слева + --accent-soft │ │  изображение страницы, цитата подсвечена,     │        │
│                                                                    │ │  прокручено к подсветке                       │        │
│                                                                    │ └───────────────────────────────────────────────┘        │
│                                                                    │ Цитата: «На 32.7 км а/д … стояли 4 лося»                │
│                                                                    │ Поля: дата, место, значение, наблюдатель — рядом «в тексте: …» │
│                                                                    │ Флаги · История правок                                   │
└────────────────────────────────────────────────────────────────────┴──────────────────────────────────────────────────────┘
```

- Без выбранной записи таблица занимает всю ширину. При выборе строки справа открывается панель записи; на ширине < 1280px она открывается поверх таблицы (drawer 560px) с затемнением. `Esc` закрывает, `J`/`K` — следующая и предыдущая запись.
- В панели порядок: заголовок и кнопки действий → **источник (страница с подсветкой)** → цитата → поля → флаги → история правок. Сейчас источник в самом низу — это главное, что нужно поменять.
- Вкладки сценариев «Вид / Автор / Фенология / Место» — сегментированный переключатель над фильтрами; каждая показывает только свои 2–3 поля.

## Таблица результатов

- Колонки: Дата · Объект (как в тексте + нормализованное название и латынь второй строкой) · Событие · Место · Значение · Источник («2020, с. 499») · Статус. Наблюдатель — во всплывающей подсказке строки и в панели; колонку убрать, она съедает ширину.
- Текст в ячейке — не больше 2 строк, остальное многоточием, полный текст в `title`.
- Значение: число и единица как в тексте (`value_raw` + `unit`), выравнивание вправо.
- Статус: «авто» — серый контурный чип, «подтверждено» — `--ok-soft`, «исправлено» — `--info-soft`, «отклонено» — `--danger-soft` и зачёркнутый объект. Флаги — янтарная точка с числом рядом со статусом.
- Шапка таблицы липкая. Пагинация снизу, по 50 строк. Загрузка — 8 строк-скелетов; пустой результат — «Ничего не найдено» + кнопки примеров жюри; ошибка — сообщение и «Повторить».

## Остальные экраны

- **Фенология:** матрица «фенофаза × год»; в ячейке дата («19.06»), фон — интенсивность `--accent-soft` → `--accent` по дню года (раньше — светлее). Клик по ячейке открывает запись в панели.
- **Место:** карта слева (Leaflet, нейтральная подложка OSM), список видов справа; точки — круги `--accent` с числом записей; места без координат — отдельным списком под картой.
- **Качество:** сверху 4 цифры (записей в эталоне, полнота, точность, F1) карточками 1×4; ниже таблица по полям с полосами-индикаторами; ниже примеры ошибок со ссылкой «открыть запись»; внизу «Неподдерживаемые страницы».
- **На проверку:** та же раскладка «таблица + панель», в таблице только записи с флагами, сортировка по уверенности ↑.
- **Документы:** таблица книг (обложка-миниатюра первой страницы, год, страниц, текстовый слой/скан, записей) + загрузка нового файла с прогрессом статуса.

## Доступность и качество

- Контраст текста ≥ 4.5:1, видимое кольцо фокуса `2px --accent` со смещением 2px, все действия доступны с клавиатуры.
- Кнопки и интерактивные элементы ≥ 32px по высоте.
- Анимации ≤ 150 мс, без анимации раскладки таблицы.
