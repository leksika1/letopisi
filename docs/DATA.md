## Источники

Файлы кейса находятся в `data/raw/`, в git не хранятся. Характеристики — из [SPEC](SPEC.md) и [решений контракта](../contracts/README.md).

| Источник | Особенности | Как читать |
|---|---|---|
| `book02_1995.pdf`, книга 2, `document_id=1` | 66 PDF-страниц, сканы машинописи, страница PDF = разворот | OCR каждой половины; PDF 40 = печатные 76–77; формула проверена только для этой книги |
| `book03_1996.pdf`, книга 3, `document_id=2` | 91 PDF-страница, сканы-развороты | OCR; соответствие PDF-страниц печатным требует отдельной проверки |
| `book27_2020.pdf`, книга 27, `document_id=3` | 732 PDF-страницы, текстовый слой на 728; по SPEC — 173 таблицы и 675 рисунков | PyMuPDF, строки с координатами и табличные парсеры; PDF-номер совпадает с печатным |
| `parameters_2020.xlsx` | 6 листов: шаблоны растений/животных, примеры запросов, сотрудники, топонимы | Целевой формат 13 колонок, каталоги и сценарии; это не четвёртая книга наблюдений |

Табличные даты могут относиться к 2018–2019 годам внутри книги 2020. В таблицах с продолжением нужно переносить шапку; объединённые ячейки дают ошибки структуры. В XLSX встречается «2022» вместо 2020; исправление года в разборе запросов явно показывается пользователю. Растительная шкала в легенде книги шире примера XLSX: **18 фаз**, коды 1–9, 10а, 10б, 11–16, стр. 76.

DOCX и XLSX поддержаны загрузчиком и локаторами абзаца/таблицы/листа, но проверенные демонстрационные данные относятся к трём PDF. UI сохраняет загруженный файл и `queued`; автоматический цикл обработки ещё не подключён.

## Что находится на стенде

По проверенным фактам задания на **22.11.2026**: 6278 записей книги 2020 и ещё 5 тестовых записей 1995. Сканы 1995/1996 проходят OCR; готовность перед показом проверяется отдельно. Пять записей 1995 — ручная тестовая расшифровка разворота ЗМУ, не результат полной OCR-обработки.

Сохранённый [release](../release/README.md) описывает **6273** извлечённые записи 2020: 3900 — правила таблиц, 2286 — LLM, 87 — подписи. Отчёт прогона: 1031 LLM-вызов, 7 пропущенных фрагментов из-за ошибок API, ни одной отброшенной по JSON Schema записи. Число в архиве и число в БД стенда различаются; причина разницы в 5 записей за 2020 не установлена в задании. Проверяйте отдельно архив, комплект загрузки и БД. Прохождение схемы подтверждает формат, а не фактическую правильность извлечения.

## Контракт записи

Обязательность, типы и enum — в [observation.schema.json](../contracts/observation.schema.json), хранение — в [schema.sql](../contracts/schema.sql), пояснения — в [contracts/README](../contracts/README.md). Неизвестное значение — `null`, исходная формулировка сохраняется.

| Поля | Смысл |
|---|---|
| `id`, `record_type` | ID; `observation`, `env_measurement` или `publication` |
| `object_type`, `object_raw`, `taxon_id` | Тип объекта, название как в тексте, нормализованный вид |
| `date_raw`, `date_from`, `date_to`, `date_precision` | Исходная дата и интервал ISO; точность: день, декада, месяц, сезон, год, диапазон |
| `obs_year` | Год наблюдения; для публикации — её год. Может отличаться от года книги |
| `toponym_raw`, `place_id`, `coords_raw`, `habitat_raw` | Исходное место, ссылка на справочник, координаты и местообитание |
| `event_raw`, `phenophase_raw`, `phenophase_id` | Событие и фенофаза до и после нормализации |
| `indicator`, `value_raw`, `value_num`, `unit` | Что измеряли, исходное и числовое значение, единица |
| `observers_raw`, `person_ids` | Люди как в источнике и упорядоченные ID; в SQL — `observation_persons` |
| `pub_authors`, `pub_year`, `pub_title`, `pub_venue` | Только для публикаций; у остальных типов `null` |
| `document_id`, `section_id`, `chunk_id` | Книга, раздел и фрагмент-основание |
| `locator`, `printed_pages` | Положение в файле и печатные страницы для шаблона — разные адресации |
| `quote`, `quote_span`, `bboxes` | Дословное основание, интервал символов, рамки подсветки |
| `note` | Контекст, оговорки, происхождение подставленного года/автора |
| `confidence`, `flags`, `status` | Эвристическая оценка и причины сомнений; `auto`, `verified`, `edited`, `rejected` |
| `extractor_version`, `created_at`, `updated_at` | Версия извлечения и время создания/обновления |

`locator` для PDF: `pdf_page` с 1, `half=L/R/null`, `printed_page`; для DOCX — `para` или `table` + `row`, для XLSX — `sheet` + `row`. `quote_span=[start,end]` — индексы Python Unicode, конец не включён. `bboxes=[[x0,y0,x1,y1]]` — доли всей страницы с началом слева сверху, для разворота не доли половины. Не найденная цитата получает `quote_not_found`, пустые рамки и `quote_span=null`.

`years` в поиске фильтрует `obs_year`, `doc_years` — `documents.year`. Книга 2020 содержит наблюдения 2018 и 2019 из таблиц. Флаг `year_outside_book` отмечает это различие и сам по себе не означает ошибку. Наблюдатель может быть взят из авторов раздела с пометкой в `note`: «наблюдатель по автору раздела». Источник при ручной правке неизменяем, действия пишутся в `observation_edits`.

Экспорт использует [export_columns.json](../contracts/export_columns.json): 13 колонок шаблона плюс «Источник (ссылка)» и «Достоверность». CSV — UTF-8 с BOM, `;`; XLSX содержит ссылку на карточку, из неё открывается оригинал.

## Справочники

| Данные | Состав и применение |
|---|---|
| `taxa`, `taxon_names` | Стартовые фикстуры: 32 вида, 103 имени; accepted/synonym/variant, русское имя и латынь, род и таксономия |
| `places`, `place_names` | 37 топонимов из XLSX и варианты; категория отличает одноимённые реку/гору. В каталоге XLSX координат нет |
| `persons` | 15 уникальных фамилий, годы работы; «Сметанников» и «Сметанникова» не объединяются |
| `phenophases` | 18 фаз растений из легенды 2020 с BBCH и 8 фаз животных; «зацветание» → фаза 5 |
| `dictionaries/*.csv` | Обогащение: GBIF, синонимы, координаты и материалы ручной сверки |

`pipeline/normalize/dicts.py` объединяет фикстуры с CSV по ID. Но текущий `pipeline/load.py` загружает только JSON/JSONL комплекта: расширенные CSV автоматически в БД не попадают. Поэтому наличие синонимов или координат в репозитории не доказывает их доступность поиску на стенде; [исправление B-5](tasks/B-5.md) запланировано. Карта сейчас почти пустая.

[gbif_enrich.py](../dictionaries/scripts/gbif_enrich.py) дополняет таксономию и имена, пишет `gbif_matches.csv` и `review_taxa.csv`; [geocode_places.py](../dictionaries/scripts/geocode_places.py) использует Nominatim/OSM, пишет `places.csv`, `review_places.csv`. Неуверенные совпадения требуют проверки. Координаты справочника не заменяют координаты встречи; три стартовые точки `manual_approx` приблизительны, около ±5 км. Источники: GBIF; OpenStreetMap contributors, ODbL.

## Оценка качества

Метод — [METHOD, раздел 8](METHOD.md#8-оценка-качества); реализация — [evaluate.py](../pipeline/eval/evaluate.py). Эталон — [gold/template.csv](../gold/template.csv), 13 колонок плюс PDF-страница, документ, цитата, UTF-8 BOM, `;`. Контрольный [sanity_2020.csv](../gold/sanity_2020.csv) содержит 22 записи со стр. 69 и 449–450.

После распаковки результатов, из корня:

```sh
python -m pipeline.eval.evaluate --gold gold/sanity_2020.csv --scope object --out data/quality.json
```

Сопоставление учитывает документ, страницу ±1, объект, дату и слова цитаты. Выход: precision/recall/F1 по записям и полям, число размеченных/извлечённых записей, ошибки `missed`, `spurious`, `wrong_value`, неподдерживаемые страницы. `gold_version` включает имя, хеш эталона и область оценки. `--scope object` оценивает объекты эталона на его страницах; `--scope page` — все записи на размеченных страницах. Последний режим корректен только при **полной** разметке этих страниц.

P=1,0 и R≈0,91 из METHOD относятся к прежней контрольной проверке без LLM (20 из 22), а не полной книге или текущему стенду. Это не независимая оценка: нужна полная разметка разных типов страниц, включая сканы, и разбор ошибок. `contracts/fixtures/quality.json` содержит заглушки с `is_placeholder=true`; их нельзя выдавать за измерения. `/api/quality` пока не подключён, показывать отчёт нужно как файл, если он подготовлен.

По фактам задания прогон 2020 занял около 29 минут и порядка 1,5 тыс. ₽ при 1031 LLM-запросе. Это ориентир конкретного прогона, не текущий тариф и не стоимость OCR старых книг. Полный кэш при той же модели, промпте и сообщениях исключает повторные LLM-вызовы; изменённый вход или неполный кэш требует запросов.

Флаги сомнений есть примерно у 74% записей (в основном вид отсутствует в стартовом справочнике); это не доля ошибок. `confidence` — базовая оценка стратегии минус штрафы, не измеренная точность. Ограничения: OCR, слитые ячейки, страницы-картинки, локальный контекст LLM, неполные справочники, пропущенные вызовы API. Примеры для показа — [DEMO](DEMO.md).
