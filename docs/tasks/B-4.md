# Б-4. Скрипты для справочников

Папка: dictionaries/scripts/ (результат — dictionaries/*.csv).

1. gbif_enrich.py: вход — CSV с колонками name_ru, name_lat (для старта выгрузи из contracts/fixtures/taxa.json). Для каждой строки GET https://api.gbif.org/v1/species/match?name=<name_lat>, затем /v1/species/{usageKey}/synonyms. Выход — dictionaries/taxa.csv и dictionaries/taxon_names.csv в формате таблиц taxa и taxon_names из schema.sql: принятое латинское имя, род, семейство, отряд, класс, группа (по kingdom/phylum/class, список групп — в SPEC.md), gbif_key, matchType, confidence, синонимы. Строки с matchType не EXACT — в dictionaries/review_taxa.csv для ручной проверки. Кэш ответов, не более 5 запросов в секунду, нейтральный User-Agent без личных данных.
2. geocode_places.py: вход — топонимы из contracts/fixtures/places.json. Запросы к Nominatim (OSM) с viewbox заповедника «Пасвик» (примерно 68.9–69.5 с. ш., 28.6–30.2 в. д.), bounded=1, 1 запрос в секунду. Выход — dictionaries/places.csv (name, lat, lon, source, found) и review_places.csv для ненайденных.

Готово, когда: скрипты отрабатывают без ошибок; есть тесты на разбор ответов (на сохранённых JSON, без сети).
