# Задания для Codex

Каждое задание — своя ветка и свой PR в main. Следующее начинаем, когда предыдущий PR смёрджен.

| Кто | Задания по порядку |
|---|---|
| Б (бэкенд, инфраструктура, данные) | B-1 → B-2 → B-4 → B-3 (сделано) → **B-5** (исправления по проверке стенда) |
| В (интерфейс) | V-1 → V-2 (сделано) → **V-3** (редизайн по docs/DESIGN.md); параллельно вручную — эталон по gold/template.csv |
| Ядро | исправления — docs/tasks/CORE-fixes.md |

## Как запускать

1. Подготовка один раз: `git clone https://github.com/leksika1/letopisi.git`, положить 4 файла кейса в `data/raw/`.
2. Перед каждым заданием: `git checkout main && git pull && git checkout -b b/infra` (имя ветки по заданию).
3. Открыть Codex в корне репозитория и написать одну строку:

   > Прочитай docs/tasks/_common.md и docs/tasks/B-1.md и выполни задание.

4. Самому запустить тесты или сборку из раздела «Готово, когда», проверить руками один сценарий. Отчёту Codex на слово не верим.
5. `git push -u origin <ветка>` и открыть PR. Ревью делает владелец ядра.
