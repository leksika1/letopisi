# Б-2. Загрузчики файлов

Папка: pipeline/ingest/.

Выход всех загрузчиков — список Chunk строго по таблице chunks из contracts/schema.sql и $defs/Chunk из observation.schema.json; сохраняем в data/chunks/<document_id>.jsonl. Для PDF обязательно заполняй Chunk.lines (строки со смещениями start/end в text и bbox в долях страницы) — по ним подсвечивается цитата. Образец формата — pipeline/devtools/quick_chunks.py в ветке core/extract (временный дампер ядра; твой ingest его заменит).

1. pdf.py: PyMuPDF. По каждой странице проверь текстовый слой (меньше 50 символов = скан). Слой есть — бери блоки и строки с bbox. Скан — рендер страницы в PNG 200 dpi и вызов ocr.py. PNG страниц сохраняй в data/pages/<document_id>/<n>.png (нужны интерфейсу). bbox — в долях от ширины и высоты страницы (0..1).
   Сканы 1995 и 1996 — развороты: страница PDF шире высоты = две страницы книги. Режь пополам, OCR делай по половинам, locator = {"pdf_page", "half": "L" или "R", "printed_page"}. printed_page — номер внизу половины (последняя строка-число из OCR). Сверься с формулой из contracts/README.md (для 1995: левая печатная = 2·pdf_page − 4). Не нашёлся — null.
   Таблицы книги 2020: page.find_tables(); каждая строка таблицы = chunk kind=table_row, text = «Заголовок: значение; ...». Остальной текст — абзацами.
2. ocr.py: Yandex Vision OCR, POST https://ocr.api.cloud.yandex.net/ocr/v1/recognizeText, model page, languageCodes ru и en, заголовки Authorization: Api-Key <YC_API_KEY> и x-folder-id: <YC_FOLDER_ID>. Повтор при 429/5xx, кэш ответа на диск по sha256 картинки (data/ocr_cache/), чтобы не платить дважды. Возвращай строки с bbox. Страницы с низкой уверенностью OCR помечай.
3. docx.py: python-docx. Абзацы и таблицы в порядке документа. locator = {"para": i} или {"table": t, "row": r}. Строка таблицы — «Заголовок: значение; ...».
4. tables.py: XLSX/CSV через pandas, каждая строка = chunk kind=table_row, locator = {"sheet", "row"}.
5. CLI: python -m pipeline.ingest <файл> --document-id <id>.

Тесты: маленькие PDF (с текстом и с картинкой), DOCX и XLSX создай в тестах кодом; OCR в тестах мокай.
Готово, когда: pytest зелёный и для book27_2020.pdf получен JSONL; выведи статистику: страниц, из них сканов, chunks, таблиц. Сканы через настоящий OCR прогоняй, только если в окружении есть YC_API_KEY.
