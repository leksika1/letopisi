# В-2. Источник, правка и остальные экраны

Папка: frontend/. Каркас из В-1 уже есть.

1. Клик по строке открывает панель справа (GET /api/observations/{id}). Верх: все поля записи; рядом с каждым нормализованным — исходная формулировка (*_raw); флаги понятным текстом. Низ: источник. Для PDF — картинка /api/documents/{id}/pages/{n}.png с полупрозрачными прямоугольниками по bboxes (доли 0..1), скролл к подсветке, зум; для разворотов (locator.half = L или R) подсветка на нужной половине. Для DOCX/XLSX — текст chunk с выделенной цитатой по quote_span. Кнопка «Открыть оригинал» (файл на нужной странице, #page=n).
2. Кнопки «Верно», «Исправить», «Отклонить». «Исправить» — форма по полям с автодополнением из /api/suggest/*, PATCH, история правок под формой. Страница «На проверку»: записи с флагами, переход к следующей клавишами J и K.
3. Вкладка «Фенология»: GET /api/phenology → таблица «фенофаза × год», в ячейке дата, клик открывает запись. Вкладка «Место»: карта Leaflet + OSM с точками places, у которых есть координаты; клик — список видов из /api/places/{id}/species.
4. Страницы «Сохранённые запросы», «Документы» (список + загрузка нового файла со статусом обработки) и «Качество» (GET /api/quality: таблица precision/recall по полям, примеры ошибок со ссылками на записи, список неподдерживаемых страниц).

Готово, когда: build без ошибок; на моках подсветка совпадает с bbox из фикстур, правка уходит PATCH-запросом и появляется в истории.
