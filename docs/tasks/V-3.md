# В-3. Редизайн интерфейса по docs/DESIGN.md

Папка: frontend/. Контракт API, запросы и моки не меняются — только вид, раскладка и тексты.

Сначала прочитай docs/DESIGN.md целиком — это требования, а не пожелания. Затем запусти фронтенд против стенда или моков и сравни с текущим видом.

Что сделать (по порядку, каждый пункт — отдельный коммит):

1. **Токены и типографика.** `src/styles/tokens.css` с переменными из DESIGN.md, Tailwind-тема берёт цвета из них. Шрифты Inter и PT Serif (из `@fontsource`, без внешних CDN — стенд может работать без доступа к Google Fonts). Все подписи полей — обычный регистр.
2. **Шапка и блок запроса.** Шапка 56px. Строка запроса во всю ширину, кнопка «Найти», под ней 4 примера жюри чипами, под ними строка «Понято: …» с чипами фильтров и предупреждениями разбора (`warnings` из /api/query/parse, например «2022 → 2020»).
3. **Фильтры.** Одна строка из 5 основных фильтров-выпадашек + «Все фильтры» (раскрывает текущую полную панель) + «только сомнительные». Вкладки сценариев — сегментированный переключатель; каждая показывает только свои поля.
4. **Таблица.** Колонки и правила из раздела «Таблица результатов»: без колонки «Автор», 2 строки текста, табличные цифры, значения вправо, чипы статусов и янтарная точка флагов, липкая шапка, скелеты загрузки, пустое и ошибочное состояния.
5. **Раскладка «таблица + панель».** При выборе записи — разделение 56/44 на ширине ≥ 1280px, drawer 560px на меньшей. Панель sticky. Порядок блоков: заголовок + действия → источник с подсветкой → цитата → поля → флаги → история. `Esc`, `J`/`K`.
6. **Фенология, Место, Качество, На проверку, Документы** — по разделу «Остальные экраны».

Не делай: тёмную тему, анимации раскладки, новые зависимости тяжелее 50 КБ gzip (кроме шрифтов), изменения в contracts/ и backend/.

Готово, когда:
- `npm run build`, `tsc` и `npm test` без ошибок; существующие тесты не удалены (обнови селекторы, если поменялась разметка);
- в PR приложены скриншоты 1440×900, 1280×800 и 1024×768: главный экран с примером жюри «лось по хронологии» и открытой записью; фенология герани лесной; страница «Качество»;
- на всех трёх разрешениях нет горизонтального скролла страницы, подсветка цитаты совпадает с текстом на странице при 100% и 150%;
- в отчёте — список того, что из DESIGN.md не удалось сделать и почему.
