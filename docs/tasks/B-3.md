# Б-3. Эндпоинты

Папка: backend/ (кроме backend/app/search/ — его пишет другой человек).

Реализуй по contracts/openapi.yaml ровно эти эндпоинты:
- GET /api/documents, GET /api/documents/{id}/file, GET /api/documents/{id}/pages/{n}.png;
- POST /api/documents — сохранить файл, создать documents со status=queued, запустить BackgroundTask с вызовом pipeline.run(document_id) (пока заглушка);
- GET /api/observations/{id};
- PATCH /api/observations/{id} — каждое изменённое поле пишется строкой в observation_edits; status становится edited, verified или rejected по action;
- GET/POST/DELETE /api/saved-queries;
- GET /api/export (format=xlsx|csv) — фильтры передай в search() из backend/app/search/; если её ещё нет, используй заглушку с тем же интерфейсом.

Колонки выгрузки — ровно в порядке contracts/export_columns.json (13 колонок шаблона заповедника + «Источник (ссылка)» и «Достоверность»). В xlsx: закреплённая строка заголовков, автофильтр, ширина колонок по содержимому. CSV в UTF-8 с BOM и разделителем «;», чтобы Excel открыл кириллицу.

Готово, когда: pytest с httpx на фикстурах покрывает каждый эндпоинт, ответы валидируются по openapi.yaml, xlsx открывается openpyxl и содержит кириллицу без кракозябр.
