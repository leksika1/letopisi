# В-1. Каркас фронтенда и поиск

Папка: frontend/.

1. Vite + React 18 + TypeScript strict. Типы API генерируй из contracts/openapi.yaml (openapi-typescript), запросы — TanStack Query. Мок-сервер: MSW с ответами из contracts/fixtures/, включается VITE_MOCK=1. Прокси /api на localhost:8000.
2. Главная = поиск. Сверху строка «Спросите обычными словами»: POST /api/query/parse → фильтры показываются чипами, каждый можно удалить или поправить. Ниже панель фильтров: вид (автодополнение /api/suggest/taxa по русскому, латыни, роду), группа, наблюдатель, место, фенофаза, показатель, диапазон дат, годы наблюдения (years) и годы книги (doc_years), документ, «только сомнительные». Фильтры синхронизированы с URL, ссылкой можно поделиться.
3. Таблица результатов (TanStack Table): дата, объект (как в тексте + латынь), событие, место, значение с единицей, автор, источник (год книги, стр.), иконка статуса и флагов. Сортировка, пагинация, кнопки «Скачать Excel» и «CSV» (GET /api/export с теми же фильтрами), «Сохранить запрос».
4. Вкладки-сценарии над фильтрами: «Вид», «Автор», «Фенология», «Место» — предустанавливают нужные поля. Плюс 4 кнопки-примера из contracts/fixtures/saved_queries.json (приёмочные запросы жюри).

Русский интерфейс, спокойный научный стиль, можно Tailwind, без тяжёлых UI-библиотек.
Готово, когда: npm run build и tsc без ошибок; с VITE_MOCK=1 все четыре сценария и 4 примера дают строки из фикстур.
