# Общие правила для каждого задания (Codex читает это первым)

Проект: веб-сервис «Цифровые Летописи природы». Летописи заповедника «Пасвик» (PDF-сканы, PDF с текстом, DOCX, XLSX) превращаются в базу наблюдений с поиском и ссылкой на источник.

Сначала прочитай docs/SPEC.md и всё в contracts/: observation.schema.json, schema.sql, openapi.yaml, export_columns.json, fixtures/, README.md (особенно раздел «Решения»). Это источник правды.

Ограничения:
- Не меняй ничего в contracts/ и docs/. Если контракта не хватает — остановись и напиши, чего именно не хватает.
- Меняй файлы только в папках, названных в задании.
- Не коммить ключи, токены, .env, файлы из data/.
- Не пушь в main и не мёрджи сам. Работай в ветке, которую создал человек.
- Python 3.12, типизация, ruff; фронтенд — TypeScript strict.
- Данные кейса лежат в data/raw/ (в .gitignore): book02_1995.pdf, book03_1996.pdf (сканы, страница PDF = разворот), book27_2020.pdf (с текстом), parameters_2020.xlsx.

В конце кратко перечисли: что изменил, какие команды запустил для проверки и с каким результатом, что не сделано.
