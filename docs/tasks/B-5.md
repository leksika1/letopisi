# Б-5. Исправления по проверке стенда: качество, справочники, места

Папки: backend/app/routers/ (новый файл quality.py и places.py), backend/app/main.py (подключение роутеров), pipeline/load.py, infra/stand_setup.sh, backend/tests/.
Не трогай backend/app/search/ и pipeline/extract|normalize|eval — это ядро.

Найдено при проверке стенда 22.11 (база с 6278 записями книги 2020):

1. **GET /api/quality отвечает 404.** Страница «Качество» во фронтенде пустая. Эндпоинт описан в contracts/openapi.yaml (ответ — `$defs/Quality`).
   Реализуй backend/app/routers/quality.py: отдаёт файл `DATA_DIR/quality.json` (его пишет `python -m pipeline.eval.evaluate`), проверяет его по схеме; если файла нет — 200 с пустыми метриками и полем-пояснением по контракту (не 404). Подключи роутер в main.py.
   В infra/stand_setup.sh после загрузки данных: скопировать `data/quality.json` в контейнер (`docker compose cp ../data/quality.json backend:/app/data/quality.json`), если файл есть. В release/ его пока нет — добавь в stand_setup.sh шаг `python3 -m pipeline.eval.evaluate` на хосте ПОСЛЕ распаковки (нужен pip install rapidfuzz pymorphy3 в venv; если не ставится — пропусти шаг с сообщением).

2. **Справочники из dictionaries/*.csv не попадают в базу.** load.py грузит только contracts/fixtures. Из-за этого:
   - у всех мест на карте нет координат (в фикстурах они у 3 мест, а в dictionaries/places.csv — у 17 из 37);
   - 535 названий и синонимов из dictionaries/taxon_names.csv не участвуют в поиске (в базе только 103 названия).
   Добавь в load.py шаг «справочники»: после фикстур применить dictionaries/places.csv (UPDATE lat/lon/coords_source по id (колонки id, lat, lon, coords_source), строки с пустыми координатами пропускать), dictionaries/taxon_names.csv (колонки id, taxon_id, name, lang, kind; INSERT … ON CONFLICT DO NOTHING), dictionaries/taxa.csv (UPDATE gbif_key, genus, family, order, class, group_ru по id). Идемпотентно, как остальной загрузчик. Флаг `--no-dictionaries`, чтобы тесты фикстур не менялись.

3. **Нет GET /api/places** (отмечено в PR В-2: карта берёт места из текущей выдачи). Добавь в openapi-совместимом виде GET /api/places?with_coords=true → [{id, name, category, lat, lon, observations_count}]. Контракт не меняй: опиши эндпоинт в отчёте, владелец ядра внесёт его в contracts/openapi.yaml.

Готово, когда:
- pytest зелёный (новые тесты: quality с файлом и без; загрузка справочников дважды даёт те же числа; places с координатами);
- на свежей базе после `python pipeline/load.py data/stand_bundle` в таблице places ≥ 15 мест с координатами, в taxon_names ≥ 500 строк;
- `curl /api/quality` → 200, `curl /api/places?with_coords=true` → непустой список.
