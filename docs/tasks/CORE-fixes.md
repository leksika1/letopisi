# Ядро: исправления по проверке стенда (делает владелец ядра)

Найдено 22.11 на полной базе книги 2020 (6278 записей). Порядок — по влиянию на оценку жюри.

| # | Баг | Пример | Где | Исправление |
|---|---|---|---|---|
| C-1 | Разбор запроса обычными словами кладёт всю фразу в `q` → полнотекстовый фильтр почти ничего не находит | «когда цвела черника в 2019 году на Калкупя» → `q` = вся фраза | backend/app/search/query_parse.py | LLM не заполняет `q`; в `q` идут только несопоставленные значимые слова и только если их нет в фильтрах; тест на 10 фразах |
| C-2 | Сезоны и части года не становятся датами | «зимой», «весной 2020», «в начале лета» → date_from/date_to отброшены | query_parse.py, pipeline/normalize/dates.py | правило «сезон → диапазон месяцев» (зима = дек–фев), общая функция для разбора запросов и текста |
| C-3 | Ложные срабатывания текстового поиска вида | «лось» находит «лососевые рыбы» (основа «лос» как префикс) | backend/app/search/resolve.py (`stem`, `term_regex`) | для основ ≤ 4 букв — только формы слова (лексема pymorphy3) с границей слова, а не префикс; тест «лось» ≠ «лосось» |
| C-4 | Период из заголовка таблицы принят за дату наблюдения | «концентрация Cu в древесине» с датой 1937–1970 (это возраст древостоя), стоит первой при сортировке по дате | pipeline/extract (таблицы, промпт) | годы-диапазоны шире 5 лет в таблицах не считать датой наблюдения: date = год книги + флаг `date_ambiguous`, исходный текст — в note; пересобрать release/ без нового прогона LLM (кэш) |
| C-5 | Сканы 1995 и 1996 не обработаны: в базе 5 ручных записей за 1995 и 0 за 1996 | приёмочный запрос 1 (Макарова и Сметанников) работает только на тестовых записях | pipeline (OCR из B-2 + ядро) | OCR 157 разворотов (Vision OCR, кэш) → разделы по заголовкам → извлечение → release/book02_1995, book03_1996 → стенд |
| C-6 | Единица в родительном падеже не согласуется с числом | «4 особей», «2 особей» | pipeline/extract/extractor.py (`split_value`) | хранить единицу в именительном («особь») и склонять при выводе, либо выводить `value_raw` целиком как в тексте |
