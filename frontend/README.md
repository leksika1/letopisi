# frontend — интерфейс «Цифровых Летописей природы»

Vite + React 18 + TypeScript (strict), TanStack Query / Table, Tailwind, Leaflet + OSM, MSW для моков.

## Запуск

```bash
cd frontend
npm ci
npm run dev:mock     # на моках из contracts/fixtures (VITE_MOCK=1), http://localhost:5173
npm run dev          # с настоящим бэкендом: /api проксируется на http://localhost:8000
npm run build        # tsc + сборка в dist/ (её отдаёт nginx)
npm test             # vitest: мок-движок, 4 приёмочных запроса, PATCH, URL-фильтры
npm run gen:api      # перегенерировать src/api/schema.d.ts из contracts/openapi.yaml
```

## Экраны

- **Поиск** (`/`): строка «Спросите обычными словами» (`POST /api/query/parse`), под ней чипы фильтров: × удаляет фильтр, клик по чипу ставит фокус в его поле. Панель фильтров, вкладки-сценарии «Вид / Автор / Фенология / Место», 4 кнопки-примера из `contracts/fixtures/saved_queries.json`, таблица с сортировкой и пагинацией, выгрузка Excel/CSV, «Сохранить запрос». Все фильтры хранятся в URL.
- Карточка записи, «На проверку», фенология, карта, «Сохранённые запросы», «Документы» и «Качество» появятся в V-2.

## Режим моков

`src/mocks/` реализует контракт поверх фикстур: фильтры (И между фильтрами, ИЛИ внутри массива, пересечение дат, без `rejected` по умолчанию), `labels`, разбор запроса, подсказки, фенологию, виды места, PATCH с записью в историю, выгрузку по `export_columns.json`, сохранённые запросы, загрузку документов. Изменения живут до перезагрузки страницы. Оригиналов PDF в git нет, поэтому `pages/{n}.png` отдаёт SVG-заглушку с теми же пропорциями. Подсветка рисуется в долях 0..1 и совпадает с `bboxes` фикстур.

## Чего не хватает в контракте

- **Подписи по id** (вид, место, фенофаза) для чипов в ссылке, открытой с нуля. Подписи собираются из подсказок, из `labels` в результатах и из `/documents` и кэшируются в браузере.
