# Найденные ошибки «Цифровых Летописей природы»

Исходная проверка 22 ноября 2026 года на коммите `90db6cf` охватила 17 операций OpenAPI и шесть экранных маршрутов. Из 62 сквозных тестов 52 прошли. Остальные десять воспроизвели восемь ошибок на обычной сборке и на сборке со счётчиками. [Команды запуска и условия стенда](README.md)

## Восемь ошибок исходного прогона

| Где | Как воспроизвести | Что произошло |
|---|---|---|
| Качество | Открыть экран качества и вызвать `GET /api/quality` с `document_id=3` и без него. | Два запроса вернули 404, экран не показал метрики. Офлайн-оценщик сформировал валидный JSON. |
| Обработка загрузок | Загрузить новый DOCX с текстом и таблицей наблюдений, проверить статус и поиск по книге. | После 201 документ остался в `queued`, число наблюдений осталось нулевым. Фоновая функция только записывала сообщение в лог. |
| Очередь проверки | Создать выборку из 516 записей с флагами, открыть очередь и перейти к последним записям. | Экран загрузил только первые 500. |
| Карта | Открыть вкладку места для полной книги 2020 года с сортировкой по дате. | Среди 6 273 записей есть 31 идентификатор места. Карта учла 4 из первых 500 записей и подписала 2 точки с координатами как «2 из 4». |
| Экспортная ссылка | В CSV открыть ссылку на наблюдение № 6 с `?page=76`, закрыть карточку. | Страница PDF стала страницей поиска. Появились пустая таблица и надпись «стр. 76 из 1». |
| Редактор | У наблюдения выбрать «публикация», заполнить заголовок и год, сохранить. | Форма отправила старый тип объекта. PATCH вернул 422. |
| Вложенная таблица DOCX | Выполнить импорт DOCX, в котором наблюдение записано во внутренней таблице. | В JSONL отсутствует строка внутренней таблицы. Контракт описывает `{table, row}`; порядок нумерации вложенных таблиц требует решения владельца контракта. |
| Подтверждение цитаты | Подать извлекателю фрагмент и ответ модели, где с источником совпадает только слово «полёвки». | Извлекатель принял одно слово за привязку целого предложения и не выставил `quote_not_found`. |

## Остальные находки на стенде

* Загрузчик прочитал справочники фикстур, пропустив обогащённые CSV. Координаты были у 3 мест, хотя CSV содержал координаты 17. У реки Паз API вернул пустые координаты. Синонимы не попали в поиск, а наблюдение с таксоном только из CSV получило ошибку внешнего ключа.
* В PostgreSQL 16.6 на Windows с локалью `C` начальная схема прерывается на `current_setting('lc_ctype')`, когда `pg_trgm` не распознаёт кириллицу. На `en-US` запуск прошёл. В Compose настроено `en_US.utf8`. Место ошибки — [строка в контрактной миграции](../../contracts/schema.sql#L17).
* В «Летопись природы.zip» книга за 1995 год имеет размер 0 байт. Прежний скрипт подбирал оригинал по году в имени. SHA-256 всех трёх книг совпал с контрактом в компактном архиве. Импорт в QA-ветке проверяет хеши.
* На повторном развёртывании Docker вкладывал новый каталог `stand_bundle` в старый. Загрузчик читал предыдущую версию. Исправленный путь проверен на Linux по содержимому файла после двух копирований.

## Ошибки, исправленные к исходному прогону

| Область | Исправление и проверка |
|---|---|
| Ссылки на оригиналы | PDF отдаётся с именем файла и открывается в браузере. Проверены оригинальные байты, страница и подсветка цитаты. |
| Импорт таблиц и PDF | Номера строк CSV/XLSX сохраняют позиции исходного документа, включая пустые строки. Скан обложки не скрывает текст следующих страниц. API и извлечение одинаково определяют одиночные страницы и развороты. |
| Редактирование | Несовместимые даты, поля публикации и флаги отклоняются. После смены года пересчитывается `year_outside_book`. Новые записи журнала следуют за импортированными, история совпадает с сохранённым состоянием карточки. |
| Повторный импорт | Конфликт ID или хеша документа останавливает транзакцию до привязки чужих записей. |
| Справочник GBIF | Каноническое имя и синоним сохраняют ID таксона при перестановке и повторной обработке. Конфликты идентификаторов обнаруживаются до замены файлов. |
| Выгрузка XLSX | Экспорт формирует строку и ссылку по известному номеру, устраняя повторный обход накопленного листа при каждой записи. |

Владелец ядра также зарегистрировал ошибки разбора свободного текста и сезонов, ложное совпадение «лось» с «лососевые», неверную дату из заголовка таблицы и форму единицы измерения. Там же отмечены неполное извлечение из сканов 1995–1996 годов и ограничение эталона из 22 записей. Это наблюдения команды по полной книге.
